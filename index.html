Guide d'installation en 3 étapes

Passez de l'archive téléchargée à votre bureau OnyxOS en quelques minutes.

ÉTAPE 01

Reconstituer l'ISO

Placez tous les volumes (.z01, .z02…, .zip) dans un même dossier et extrayez le fichier .zip avec 7-Zip (Windows) ou via terminal (Linux) :

zip -s 0 OnyxOS-*.zip --out full.zip && unzip full.zip
ÉTAPE 02

Créer la clé USB

Flashez l'image .iso sur une clé USB (8 Go minimum) avec Rufus, Ventoy ou BalenaEtcher, puis démarrez votre PC sur la clé.

ÉTAPE 03

Mettre à jour

Une fois installé, profitez de mises à jour ultra-rapides via KDE Discover ou en un mot dans Konsole :

onyxos-update
